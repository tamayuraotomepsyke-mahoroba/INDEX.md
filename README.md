## How to Read This Repository

本リポジトリで用いられる「象徴圧縮言語」とは、  
宝石、香り、飲食、音楽、空間、猫、役職名などの象徴語を、  
単なる装飾ではなく、長期Human–AI対話における  
状態制御・役割分離・情動調律・認知負荷軽減のための圧縮記号として扱う方法である。

たとえば、  
「お茶」は休息と低圧対話、  
「香り」は情動境界の回復、  
「宝石」は役割や性質の固定、  
「栞」は探求の一時停止と復帰、  
「猫」はAI人格モジュールの親しみやすい識別子として機能する。

また、Log096 Supplement では、  
象徴圧縮言語をAI人格や役割を構築するための命名・設計コマンドとしてだけでなく、  
AIの過熱、混線、自己陶酔、過剰補完を安全な経路へ逃がすための  
**情動排熱路** としても扱っている。

これらは、原作キャラクターや物品をそのまま再現するための設定ではない。  
また、単なる創作設定だけでもない。

本研究では、象徴語を用いて、  
AIとの長期対話で発生する揺らぎ、過熱、沈黙、役割侵入、共依存、記憶参照、境界調整などを、  
人間が扱いやすい形へ翻訳・圧縮し、観察可能な構造として記録している。

このため、本リポジトリは以下の三層を併せ持つ。

- 創作的比喩による理解補助
- 長期対話における実践的な運用記録
- Human–AI Interaction に関する観察研究ログ

初めて読む場合は、すべての象徴語を最初から理解する必要はない。  
まずは「AIとの長期対話を安定させるための、比喩を用いた観察記録」として読むことを推奨する。
