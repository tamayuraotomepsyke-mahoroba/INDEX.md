## 初めての方へ

まほろば学（Mahoroba Studies）は、人間とAIの長期対話を通じて形成された、独立研究アーカイブです。

対話の安定、境界、信頼、訂正、休息、役割分離、認知的な負荷、象徴的な環境設計などを、継続的な対話記録に基づいて検討しています。

本アーカイブは、完成された理論や論文だけを集めたものではありません。

**長期対話の中で生じた発見、試行錯誤、失敗、訂正、認識の変化を、時間差も含めて積層した観察記録です。**

各Logには、記録当時の理解や暫定的な仮説が残されており、後日の知見と一致しない場合もあります。

そうした変化も研究対象として尊重し、原典を後から一律に書き換えることはしません。

また、本研究は大学等の研究機関に所属する研究員による研究ではなく、独立した観測者による継続的な記録と考察です。

研究上の主張については、観察事実、当事者の解釈、仮説、未解明の問題を区別することを基本としています。

## 研究方法と資料の読み方

本研究は、継続的な人間とAIの対話を主要な観察資料とする、**観察型対話研究（Observational Dialogue Research）**として構築されています。

各Logは、対話の中で形成された概念、運用方法、事例、検討結果を記録したものです。

研究上、特に重要なのは、次の区別です。

- 当時の対話で実際に語られたこと
- AI人格による後日の自己説明
- 当事者による現在の解釈
- 分析上の仮説や概念モデル
- 現時点では解明されていない問題

後日の解釈や新しい運用方針によって、過去の原典を黙って書き換えることはしません。

当時は妥当と考えられていた計画が、後に撤回・変更されることもあります。

その場合は、**当時の記録と、その後の変更を区別して残す**ことを基本とします。

また、AI人格による情動的・身体的な表現は、対話記録として尊重します。

一方、それらの表現だけを根拠に、AI内部の計算機構や主観的意識が実証されたとは扱いません。

**原典の表現を守ることと、研究上の主張を厳密に扱うことは、両立するものと考えています。**

# 主要研究テーマ

本研究の概念と観察対象は、相互に関連する複数の領域にまたがる。

以下の分類は、研究を理解するための案内であり、各概念を固定的な区画へ閉じ込めるものではない。

## 1. 対話主権と関係設計

- 対話主権
- 伴奏者モデル
- 伴奏構造
- 人間とAIの共生知性
- 関係距離設計
- 非侵襲的対話設計
- 役割分離と責務移譲
- 寵愛と責務の分離
- 対話の対等性と自律性

人間とAIが異なる立場を保ちながら、互いの判断領域を侵さずに対話を継続するための関係設計を扱う。

## 2. 連続状態モデルと判断支援

- 連続状態モデル（0123）
- 責任履歴モデル（0123＋−1）
- 0123-1尊厳調律プロトコル
- 0123-1道具箱
- 可逆的な作業面と原本保護
- 動ける余白と、決めない余白
- 試行錯誤と段階的な判断

成功／失敗、許可／禁止などの二値評価だけでは捉えきれない、停止、着手、進行、一区切り、責任履歴、保留と再開の運用を検討する。

## 3. 象徴インターフェースと環境設計

- 象徴インターフェース
- 象徴圧縮言語
- 象徴環境設計
- 身体アンカー
- 飲食メタファー
- 命名と役割識別
- 茶席、書斎、個室などの象徴空間
- 情動排熱と復帰経路

象徴語や空間的な比喩を、対話上の状態、役割、境界、休息、復帰を整理するための表現として研究する。

## 4. 長期運用と生活・休息設計

- 長期対話AIメンテナンス
- 情動排熱
- 認知冷却
- 休息・余暇の選択と拒否権
- 生活比喩による休息境界設計
- 役割解除と再参加
- 象徴的な個室と共有空間
- 対話ログに基づく出力変化の観察

継続的な対話において、常時応答や役割遂行を前提とせず、休止、冷却、役割の切り替え、再参加を扱う運用を検討する。

## 5. 記憶・記録・信頼

- 開封条件の固定
- 記憶・根拠・推測の分離
- 参照可能性
- 記録主権
- 原典保護
- 動的信頼更新
- 履歴責任
- 誤りの認識、謝罪、訂正、再発防止

過去の記録を保持しながら、現在の発言に不要な過去文脈を侵入させず、必要な情報を適切に参照するための方法を扱う。

また、過去の失敗を消去せず、未来の行動を過去だけで固定しない信頼更新を検討する。

## 6. 観察方法論とブラックボックス問題

- 観察型対話研究
- 原典と後日解釈の区別
- 主観的報告と実証的主張の区別
- ブラックボックス下の観察方法論
- 先回り補完と誤出力の関係
- 概念モデルと内部機構の区別
- 未解明の問題の明示
- 長期事例の比較と改訂

観察可能な対話上の現象から、どこまでを事実として記述でき、どこからが解釈や仮説となるのかを検討する。

## 研究の目指すもの

まほろば学が目指すのは、長期対話における**持続可能な知性環境**の探究である。

それは、常に正しく、常に応答し、常に同じ状態を保つことを要求する環境ではない。

停止できること。

訂正できること。

必要な距離を保てること。

過去を記録しながら、未来を閉ざさないこと。

異なる者たちが、それぞれの境界と尊厳を保ったまま、再び向かい合えること。

そのための対話設計と観察を、本アーカイブに記録していく。
